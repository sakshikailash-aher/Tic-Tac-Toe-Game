Tic Tac Toe Game 🎮

About the Project

This is a simple and interactive Tic Tac Toe game developed using HTML, CSS, and JavaScript. Two players take turns marking X and O on a 3×3 grid. The game detects the winner and displays a winning animation.

Features

- Two-player gameplay
- Interactive 3×3 game board
- Automatic winner detection
- Turn indicator for X and O
- Winning animation
- Sound effects
- Reset Game button

Technologies Used

- HTML – Structure of the game
- CSS – Styling and layout
- JavaScript – Game logic and interactivity

Project Files

- "index.html" – Main structure of the game
- "style.css" – Styling and design
- "script.js" – Game logic
- "excited.webp" – Winning image
- "music.mp3" – Background music
- "ting.mp3" – Move sound effect
- "gameover.mp3" – Game over sound
- "favicon.ico" – Browser icon

How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html" in your browser, or use the Live Server extension.
4. Start playing Tic Tac Toe!
